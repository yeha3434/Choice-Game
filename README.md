# 选什么

一个把纠结选项变成搞怪赛跑选手的网页小游戏。

当前处于阶段 0：只有项目骨架和测试基础设施，尚未实现游戏功能。

## 本地运行

```bash
npm install
npm run dev
```

终端显示本地地址后，用浏览器打开即可。

## 验证命令

```bash
npm run build
npm test
npm run test:e2e
```

端到端测试默认使用本机已安装的 Microsoft Edge，不会额外下载浏览器内核。
